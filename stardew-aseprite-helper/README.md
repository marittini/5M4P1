# Stardew 도트 도우미 (Aseprite 확장)

Aseprite를 처음 쓰는 사람도 **스타듀밸리 바닐라 느낌의 도트**를 그릴 수 있게 돕는 확장입니다.
그림을 대신 그려 주지는 않고, 옆에서 "준비 → 색 → 다듬기 → 비교·저장"을 버튼으로 도와줍니다.

> 바닐라 그림은 이 확장에 들어 있지 않습니다. **본인 PC의 스타듀 그림 파일**을 읽어서 씁니다.
> 들어 있는 글꼴: 갈무리9 / 갈무리11 (이민서, SIL OFL 1.1 - `fonts/OFL-Galmuri.md`)

---

## 처음 한 번만 하는 준비 (약 10분)

### 1. Aseprite 한국어로 바꾸기 (선택)
[Aseprite-Korean](https://imbada.github.io/Aseprite-Korean/) 안내대로
언어 파일과 테마 파일을 확장으로 추가하고, 환경설정에서 언어를 `ko` 로 바꿉니다.

### 2. 이 확장 설치
`stardew-pixel-helper.aseprite-extension` 파일을 **더블클릭**하면 설치됩니다.
(안 되면: Aseprite 위 메뉴 **편집(Edit) > 환경설정(Preferences) > 확장(Extensions) > 확장 추가(Add Extension)**)

### 3. 도우미 창 열기
아래 둘 중 편한 곳에서 엽니다.
- **도움말(Help) > Stardew 도트 도우미 열기**
- **편집(Edit) > FX > Stardew 도우미 > 도우미 창 열기**

처음 열면 안내 창이 한 번 나옵니다.

### 4. 스타듀 그림 폴더 지정 (⑥ 설정 탭)
`spring_town.png` 버튼을 눌러 아래 둘 중 하나의 파일을 고릅니다.
- **간단한 방법**: [Stardew Sim 저장소](https://github.com/Waifuhtr/Stardew-valley-mcp) 를 **Code > Download ZIP** 으로 받아 풀고
  `web\data\img\Maps\spring_town.png`
- 내 게임 파일에서 직접: StardewXnbHack 을 게임 폴더에서 실행 → `Content (unpacked)\Maps\spring_town.png`

### 5. 갈무리9 글꼴 (⑥ 설정 탭)
**갈무리9 글꼴로 바꾸기** 버튼을 누르고 Aseprite를 껐다 켜면 메뉴와 창 글자가 전부 갈무리9로 바뀝니다. (픽셀이 딱 맞는 10 크기로 설정됩니다)
되돌리려면 **원래 글꼴로**.

> 스크립트가 파일을 읽을 때 Aseprite가 "Security(보안)" 창을 띄울 수 있습니다.
> **Give full trust to this script(이 스크립트를 완전히 신뢰)** 를 체크하고 **Allow(허용)** 를 누르면 다음부터 묻지 않습니다.

## 그리는 순서

### ① 시작
1. **무엇을 그릴까요?** 에서 고릅니다: 작은 집, 큰 건물, 나무/큰 소품, 작은 소품, 바닥 타일, NPC 초상화, NPC 걷는 모습, 직접 크기.
2. AI 목업 같은 그림을 보고 따라 그리고 싶으면 **참고 그림 깔고 따라 그리기** 를 체크하고 파일을 고릅니다.
   → 흐리게 깔리고 잠겨서, 그 위에 따라 그려도 참고 그림은 망가지지 않습니다.
3. **새 그림 만들기** 를 누르면 준비 끝:
   - 게임 크기에 맞는 캔버스, 16칸 격자 켜짐
   - 연필 1픽셀 + 픽셀 퍼펙트(선이 깔끔하게)
   - 팔레트(왼쪽 색 목록)에 스타듀 바닐라 색

### ② 색
재질별(벽돌, 돌담, 지붕, 판자, 창문, 나뭇잎, 잔디 …) 바닐라 색이 왼쪽 어두운 색부터 줄지어 있습니다.
**색을 누르면 바로 그 색으로 연필이 바뀝니다.** (오른쪽 클릭은 배경색)

**스타듀 예시 보기**: 재질을 고르고 **예시 열기** 를 누르면 실제 바닐라 그림이 새 탭에 크게 열립니다.
아래에 그리는 요령(예: "벽돌 한 줄은 4칸 높이 …")도 나옵니다.

### ③ 재질 (바닐라 무늬 입히기)
직접 한 칸씩 찍지 않고, **고른 곳을 바닐라 벽·바닥·지붕 무늬로 채웁니다.**
1. 칠할 곳을 선택합니다. (M: 사각형 선택, Q: 올가미 선택)
2. 재질 버튼을 누릅니다.

**벽 · 바닥** (바닐라 건물 벽 한가운데, 그림자·창문·테두리가 없는 곳에서 가져와 반복해도 이어지는 것만)
| 버튼 | 가져온 곳 |
|---|---|
| 노란 벽돌 | 살롱 벽 |
| 붉은 벽돌 | 살롱 벽 (색만 붉게 바꿈) |
| 돌벽 | 대장간 벽 |
| 크림 판자 | 주황 지붕 집 벽 |
| 하늘색 벽 | 병원 벽 |
| 파란 판자 | 파란 집 벽 |
| 돌바닥 | 광장 바닥 |
| 잔디 | 기본 잔디 |

**지붕** (주황 / 보라 / 어두운): 선택 영역의 **가운데 세로선**을 기준으로 왼쪽은 그늘 면, 오른쪽은 빛 받는 면 무늬로 채우고,
가운데 **용마루**와 맨 아래 **처마** 테두리를 그립니다. (체크 해제하면 무늬만)

- **이미 그린 부분만**: 먼저 아무 색으로 집 모양을 대충 칠한 뒤, 벽 부분 / 지붕 부분을 각각 대충 선택하고 누르면 칠한 모양 안에만 들어갑니다.
- **그린 명암 살리기** (벽·바닥): 대충 칠할 때 밝게 칠한 곳은 밝은 무늬, 어둡게 칠한 곳은 어두운 무늬가 됩니다.

### ④ 다듬기
- **자동으로 다듬기**: 다 그린 뒤 누르면
  - 새까만 테두리 → 옆 색에 어울리는 진한 갈색 계열로 (스타듀식)
  - 혼자 튀어나온 점 제거
  - **좌우대칭 건물이에요** 를 체크하면 왼쪽 절반에 맞춰 오른쪽을 똑같이
  - 마음에 안 들면 **Ctrl+Z 한 번**으로 전부 되돌아갑니다.
- **문제 있는 곳 보기**: 빨강(까만 테두리), 노랑(튀어나온 점), 하늘색(좌우 다른 곳)으로 표시합니다. **표시 지우기** 로 없앱니다.
- **고급 기능 보기**: 하나씩 따로 하기, 선택 영역에 벽돌 깔기 등.

### ⑤ 미리보기
- **스타듀 건물 옆에 놓고 보기**: 잔디 위 스타듀 살롱 옆에 같은 크기로 놓아 봅니다.
- **PNG로 저장**: 참고 그림·문제 표시는 빼고 저장합니다. 이 PNG를 모드에 씁니다.

## 재질 추가하기 (선택)
`catalog.lua` 에 한 줄 추가하면 ② 색 탭에 생깁니다. ③ 재질 버튼은 같은 파일 아래쪽 `C.fills`(벽·바닥), `C.roofs`(지붕)에 추가합니다. (확장 폴더: 환경설정 > 확장 > 확장 폴더 열기)
```lua
{ name = "긴 이름", short = "짧은 이름", sheet = "spring_town", x = 16, y = 16, w = 1, h = 1, note = "그리는 요령" },
```
`x, y, w, h` 는 **타일 단위**(1타일 = 16픽셀), `sheet` 는 Maps 폴더 안의 파일 이름(.png 빼고)입니다.

## 알려진 한계
- 크림색 석재(FF14 건물의 밝은 돌)는 바닐라 건물에 깨끗한 벽면이 없어서 재질 버튼에 없습니다.
- 재질을 추가하려면 `catalog.lua` 의 `C.fills` / `C.roofs` 에 픽셀 좌표(x, y, 너비, 높이)로 한 줄 추가합니다.

## 확인한 환경
Aseprite 1.3 (소스 빌드, 1920×1080)에서 모든 탭과 버튼을 실제로 눌러 확인했습니다.
스팀판 1.3.18 에도 같은 기능(글꼴 설정 포함)이 있습니다. 오류가 나면 메시지를 알려 주세요.
