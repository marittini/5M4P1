# Stardew 도트 도우미 (Aseprite 확장)

바닐라 스타듀밸리 그림을 **참고 자료**로 삼아, 직접 찍는 도트를 바닐라 느낌에 맞추도록 돕는 Aseprite 확장입니다.
그림을 대신 그려주지 않습니다. 재질 예시, 팔레트, 검사, 반복 작업(외곽선·잡티·대칭·벽돌)을 도와줍니다.

> 바닐라 그림은 이 확장에 들어 있지 않습니다. **본인 PC의 스타듀밸리 게임 파일**을 읽어서 씁니다.

## 1. 준비: 게임 파일 풀기 (처음 한 번)

스타듀 그림은 `.xnb` 형식이라 그대로는 못 읽습니다. **StardewXnbHack**으로 PNG로 풀어 주세요.

1. StardewXnbHack 최신 버전을 내려받습니다 (GitHub: Pathoschild/StardewXnbHack → Releases).
2. 압축을 풀어 나온 실행 파일을 **스타듀밸리 게임 폴더**에 넣고 실행합니다.
3. 게임 폴더에 `Content (unpacked)` 폴더가 생깁니다. 그 안의 `Maps` 폴더를 씁니다.
   - 예: `...\Stardew Valley\Content (unpacked)\Maps\spring_town.png`

**간단한 대안: Stardew Sim 저장소의 PNG 쓰기**
[Waifuhtr/Stardew-valley-mcp](https://github.com/Waifuhtr/Stardew-valley-mcp) 저장소에 이미 PNG로 풀린 타일시트가 들어 있습니다.
GitHub에서 **Code > Download ZIP** 으로 받아 풀고, 도우미 창에서 `web\data\img\Maps\spring_town.png` 를 고르면 됩니다.
(안드로이드판 1.6.15에서 뽑은 그림이지만 PC판과 그림은 같습니다. 개인 참고용으로만 쓰세요.)

## 2. 설치

1. `stardew-pixel-helper.aseprite-extension` 파일을 더블클릭하거나,
2. Aseprite에서 **편집(Edit) > 환경설정(Preferences) > 확장(Extensions) > 확장 추가(Add Extension)** 로 선택합니다.

설치 후 **편집(Edit) > Stardew 도우미 > 도우미 창 열기** 를 누르면 창이 열립니다.

## 3. 사용법

### ① 스타듀 게임 파일
`spring_town.png` 칸 옆 버튼으로 `Content (unpacked)\Maps\spring_town.png` 를 고릅니다. (한 번만 하면 기억합니다)

### ② 바닐라 재질 도감
- **재질**: 벽돌, 석재, 지붕, 판자벽, 창문, 문, 분수, 나무, 잔디 등 20종. 아래에 그리는 요령 메모가 나옵니다.
- **레퍼런스 열기**: 그 재질의 바닐라 타일을 새 그림으로 엽니다 (16px 격자 설정됨). 확대해서 보고 따라 찍으세요.
- **팔레트로 적용 / 팔레트에 추가**: 그 재질에 실제로 쓰인 색을 지금 그림의 팔레트로 넣습니다.
- **전체 바닐라 팔레트**: 도감 전체 재질의 주요 색(최대 255색)을 팔레트로 넣습니다.

### ③ 검사 (현재 팔레트 기준)
지금 레이어를 검사해서 알려줍니다. "문제 위치 표시 레이어"를 켜면 위치를 색으로 표시한 레이어를 만들어 줍니다 (다 보면 지우세요).
- 분홍: 팔레트에 없는 색
- 빨강: 순검정 픽셀 (바닐라는 검정 외곽선을 거의 안 씁니다)
- 노랑: 외톨이/삐죽 픽셀
- 하늘색: 좌우 비대칭 (선택 영역이 있으면 그 영역 가운데, 없으면 그림 가운데 기준)

### ④ 보정 (선택 영역이 있으면 그 안에만, Ctrl+Z로 되돌리기 가능)
- **팔레트 색으로 맞추기**: 모든 색을 팔레트에서 눈으로 보기에 가장 가까운 색으로 바꿉니다.
- **검은 외곽선 → 재질색**: 검정/아주 어두운 *선*을, 맞닿은 재질에 맞는 진한 갈색·적갈색 등으로 바꿉니다. 문·유리처럼 넓게 어두운 면은 그대로 둡니다.
- **외톨이 픽셀 제거**: 실루엣에서 튀어나온 1픽셀짜리를 지웁니다.
- **왼쪽 기준 좌우대칭**: 왼쪽 절반을 뒤집어 오른쪽에 덮어씁니다.
- **선택 영역에 벽돌 깔기**: 영역을 선택하고, 도감에서 벽돌 재질을 고른 뒤 누르면 그 재질의 명암 5단계로 바닐라식 벽돌을 깝니다.
  - 단 높이 4 / 벽돌 폭 8 이 바닐라 기본값입니다. 원래 어두웠던 부분(그늘)은 한 단계 어둡게 유지됩니다.

### ⑤ 미리보기
**바닐라 건물 옆에 놓고 보기**: 잔디 위에 바닐라 살롱과 지금 그림을 실제 게임 배율로 나란히 놓은 새 그림을 엽니다.

## 재질 추가하기

`catalog.lua` 를 열어 항목을 추가하면 됩니다. (확장 폴더: Aseprite > 편집 > 환경설정 > 확장 > 확장 폴더 열기)

```lua
{ name = "내 재질 이름", sheet = "spring_town", x = 16, y = 18, w = 1, h = 2, note = "메모" },
```
- `sheet`: `Content (unpacked)\Maps` 안의 파일 이름 (.png 빼고)
- `x, y, w, h`: **타일 단위** (1타일 = 16픽셀)

## 알려진 한계
- RGB 색상 모드 전용입니다 (인덱스 모드는 스프라이트 > 색상 모드 > RGB 로 바꿔 쓰세요).
- 이 확장은 실제 Aseprite에서 아직 실행해 보지 않았습니다. 핵심 기능은 테스트로 확인했지만, 창이나 메뉴에서 오류가 나면 오류 메시지를 알려 주세요.
